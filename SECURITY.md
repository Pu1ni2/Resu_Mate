# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ResuMate AI, please report it responsibly.

**Do NOT open a public issue.**

Instead, email **saipunithkolla@gmail.com** with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment:** Within 48 hours
- **Initial Assessment:** Within 5 business days
- **Resolution:** Dependent on severity, typically within 30 days

## Scope

This policy covers:
- The ResuMate AI web application
- Backend API endpoints
- Interview system (LiveKit integration)
- Candidate and hiring manager portals

## Out of Scope

- Third-party services (OpenAI, LiveKit, Simli, Render, Fly.io)
- Issues in dependencies not maintained by this project

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest (main branch) | Yes |
| Older commits | No |

## Disclosure Policy

We follow coordinated disclosure. Please allow reasonable time for a fix before public disclosure. Credit will be given to reporters unless anonymity is requested.
